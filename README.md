# Expense-Tracker
    C++ Expense Tracker
💰 Expense Tracker

A console-based Expense Tracker developed in C++ as a Data Structures project.
The application allows users to add, view, search, sort, calculate, and delete expense records through a simple menu-driven interface.

📌 Project Overview

The Expense Tracker stores expense information such as:

* Expense ID
* Category
* Date
* Amount

The project demonstrates the practical implementation of fundamental Data Structures and Algorithms (DSA) concepts in C++.

✨ Features

* ➕ Add a new expense
* 📋 View all recorded expenses
* 💵 Calculate total expenses
* 🔍 Search expenses by category
* 📊 Sort expenses by amount
* 🗑️ Delete an expense using its ID
* 🚪 Exit the application

🧠 Concepts Used

This project demonstrates:

* Structures – to store expense records
* Arrays – to store multiple expenses
* Array Traversal – to display records
* Array Insertion – to add expenses
* Array Deletion – to remove expenses
* Linear Search – to search by category and ID
* Bubble Sort – to sort expenses by amount
* Functions – for modular program design
* Loops & Conditionals – for program control
* Input/Output – for user interaction

🛠️ Technologies Used

* Language: C++
* Compiler: Any standard C++ compiler
* Libraries: <iostream>, <iomanip>, <string>

▶️ How to Run

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_LINK

2. Open the project

Navigate to the project folder:

cd Expense-Tracker

3. Compile the program

Using g++:

g++ ExpenseTracker.cpp -o ExpenseTracker

4. Run the program

Windows:

ExpenseTracker.exe

Linux/macOS:

./ExpenseTracker
